What this command means

Why a context-free grammar?

Simple command signatures can be regular. Advanced mode adds recursively nested groups: FACTOR → lparen S rparen. Matching arbitrarily nested parentheses requires a stack; the CFG expresses that structure. Within this app’s 40-token limit, CYK checks membership and its parse tree determines grouping. The interpreter then checks file existence and calculates effects.

(cd src && pwd) && pwd keeps directory changes inside the group. Groups share virtual file changes, return their last exit status, and can appear inside pipelines. Advanced groups remain preview-only for real folders.

Token classes: how your command connects to the grammar

Keywords are recognized only at command positions. Other words become path, text, pattern, or command-specific flag classes. Use these lowercase terminals in your rules; uppercase names are non-terminals. Use eps for an empty production.

BEFORE YOU RUN / A formal-language playground
Simulation has limits. Permissions, symlinks, shell expansion, redirection, and external programs aren’t modeled. This is a documented subset, not a safety guarantee.

  


  
A small, explicit language.
Commands operate on an in-memory snapshot. Paths use /, are case-sensitive, and resolve from the virtual current directory. Use quotes for names with spaces. Basic mode accepts one command without flags; switch to Advanced for flags and chaining.
Advanced flow: | passes standard output; && continues on success; || continues on failure. Pipes bind more tightly; && and || associate left to right. Pipeline status comes from its last command, without pipefail. A pipeline’s cd does not change the surrounding directory. Parentheses group commands recursively; directory changes inside a group stay inside it. Quote or escape parentheses to use them as literal arguments.
Limits: one path per mkdir/touch/rm/ls/cat; one source and destination per cp/mv. No directory merging. grep uses literal substrings. Failed individual commands are atomic. No permissions, symlinks, variables, wildcard expansion, redirection, comments, background jobs or external programs. Maximum 40 tokens, 512 command characters, and 100,000 workspace entries.
Real folders: use Browse or paste a local path. Preview is read-only; Review & apply writes one supported Basic command after confirmation. Advanced commands and browser uploads remain preview-only. Changes are applied directly; no recovery copies are created. cat/grep cannot read imported contents. Excluded folders cannot be moved or removed through an ancestor.
An alternative if your browser cannot open the main folder picker. Empty directories are omitted.
Recovery: suggestions close quotes, balance group parentheses, or remove a misplaced connector/delimiter, then verify the candidate using CYK. Missing operands receive guidance without inventing file paths. Selecting a candidate shows the rejected input and reparse outcome. They are candidates, not inferred intent or globally minimal repairs.
